# Covert scan speed (researched + shipped 2026-11-21)

- Offline recipe that worked: `adb pull` every `ABAsset/*/luascript_*.assetbundles` (190, read-only, no bot pause), UnityPy TextAssets, xor `eyugame_lua_zombiesrpg`, regex the decoded bytecode for `[A-Za-z]+C2S`. Takes ~3 min.
- No request lists a kingdom's covert ops. Secret-task messages: `GetSecretInfosC2S` (own tasks), `InspectSecretTaskC2S` (one op's detail), `StartSecretTasksC2S`, `GainSecretTaskRewardC2S` / `GainOwnAllSecretTaskRewardC2S` (actions: never send). Unchecked: `WorldSearchC2S`, `WorldMapPointC2S`. The zoom-3 world map view (`WorldMapViewC2S`, max 150x200) stays the only bulk source.
- Measured (S10, 35 blocks of K263, one scan each, no ErrorCode anywhere): sequential with game-like 0.45-0.95 s gap 69-71 s; gap 0.2 58 s; gap ~0 41 s; 2, 3, 4, 6 and 10 requests in flight ALL 35.3-35.6 s. The server answers ~1 block/s, so >2 in flight buys nothing. Op counts matched across speeds (drift of ~1% per 10 min is ops changing).
- Shipped: `covert.py` FAST sweep (2 in flight, no gap), `CHAIN2` Lua, `_sweep_once`; any missed block or ErrorCode flips `FAST['on']` off until the bot restarts and redoes that sweep sequentially. `covert.LAST` (mode, secs, missed, errors, fallback) is logged after each scan ('covert sweep: ...'). Standalone `scan()` took 43 s total (37 s sweep + ~6 s overhead) vs ~2 min before.
- Test harness pattern: pause the phone bot (`aegis-ctl/pause`, wait 40 s), run a script that restores the map view + fastmap hook in a `finally`, unpause. Scripts lived in the scratch dir (sweep_speed.py, run_covert_test.py).
- the owner: distrusts a cache of old scan results (stale/bad data); will not move the bot off the phone or dedicate the PC, so multi-instance/parallel accounts are out; 'going unsafe is fine' for speed (he accepts ban risk on request speed). FarmHarder (farmharder.gg, paid cloud bot + free 'Scout' map) most likely scans with many accounts on a VPS (or a headless client) and serves everyone a shared cache.
