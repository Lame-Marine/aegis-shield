- `zoneContestMatch`: groupA/groupB, winCountMap (kingdom -> wins this season), resultList/historyResults (past rounds with each side's king), serverInfoMap.

## Storing the data (optional, bring your own database)
`aegis/kvk_sync.py` reads the Kingdom War boards (needs castle level 15). It is a dry run unless you configure a
PostgREST-compatible database: create the tables from `docs/kingdom_war_schema.sql`, set `KVK_DB_URL` and `KVK_DB_KEY`,
then `python aegis/kvk_sync.py --apply`. No database is bundled and nothing is stored by default.
